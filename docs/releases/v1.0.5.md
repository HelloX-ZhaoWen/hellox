# HelloX v1.0.5

版本：1.0.5 · 构建：98

## 更新内容

- 新增百度翻译、阿里云翻译接入，补齐品牌图标、凭证配置与申请教程。
- 移除翻译服务配置页的“官方免费说明”按钮，清理对应的无用链接属性。
- 改进截图翻译的段落识别、文本保护及请求分批处理。
- 完善截图文字编辑焦点、Markdown 图片查看与窗口交互。

## 下载与安装

支持 macOS 15 或更高版本，安装包同时包含 Apple Silicon 和 Intel 架构。

- [下载 DMG 安装镜像](https://github.com/HelloX-ZhaoWen/hellox/releases/download/v1.0.5/HelloX-1.0.5.dmg)：打开后运行“安装 HelloX.pkg”。
- [下载 PKG 安装包](https://github.com/HelloX-ZhaoWen/hellox/releases/download/v1.0.5/HelloX-1.0.5.pkg)：直接打开安装，目标位置为 `/Applications/HelloX.app`。

当前构建采用 ad-hoc 应用签名，安装包未使用 Developer ID 签名，也未经过 Apple 公证。

将安装包与对应的 `.sha256` 文件下载到同一目录后验证：

```sh
shasum -a 256 -c HelloX-1.0.5.dmg.sha256
shasum -a 256 -c HelloX-1.0.5.pkg.sha256
```
