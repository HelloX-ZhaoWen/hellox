# HelloX v1.0.4

版本：1.0.4 · 构建：97

本次发布汇总 v1.0.0 之后的功能与交互改进，提供适用于 Apple Silicon 和 Intel Mac 的 Universal 安装包。

## 更新内容

- 新增 Mac 灵动岛入口，集中访问运行中应用和全部 16 项 HelloX 工具；支持应用置顶、工具排序和全屏空间显示。
- 完善运行中应用识别，纳入具有菜单栏图标的菜单栏应用，并过滤系统辅助进程及 HelloX 自身。
- 调整 Dock 图标显示：普通工作窗口打开时显示，全部关闭后回到菜单栏模式；最小化窗口时保留 Dock 入口，点击 Dock 图标可重新打开主窗口。
- 新增“可翻译语言”面板，展示 macOS 系统翻译支持的语言，并提供跳转系统设置管理离线语言包的入口。
- 优化翻译服务设置，将本地离线翻译开关归入服务列表，并完善服务详情入口和设置搜索。
- 完善截图标注、Markdown 工作台、窗口与设置界面的交互，补充相关自动化测试。
- 更新项目说明、真实界面截图、快速上手指南及 Markdown 演示文档。

## 下载与安装

系统要求：macOS 15 或更高版本；支持 Apple Silicon 和 Intel Mac。

- [下载 DMG 安装镜像](https://github.com/HelloX-ZhaoWen/hellox/releases/download/v1.0.4/HelloX-1.0.4.dmg)：打开后运行“安装 HelloX.pkg”。
- [下载 PKG 安装包](https://github.com/HelloX-ZhaoWen/hellox/releases/download/v1.0.4/HelloX-1.0.4.pkg)：直接打开并按安装器提示操作。

安装位置为 `/Applications/HelloX.app`。升级时安装器会退出正在运行的 HelloX，安装完成后可从“应用程序”重新启动。

当前构建采用 ad-hoc 应用签名，安装包未使用 Developer ID 签名，也未经过 Apple 公证。首次安装时，macOS 可能要求在“系统设置 → 隐私与安全性”中确认。

截图和录屏需要屏幕录制权限；滚动长截图和划词翻译需要辅助功能权限。系统离线翻译需先下载相应语言包；云端翻译需自行配置服务凭证。

## 文件校验

发布页同时提供 DMG 和 PKG 的 `.sha256` 文件。将安装包与对应校验文件下载到同一目录，在该目录运行：

```sh
shasum -a 256 -c HelloX-1.0.4.dmg.sha256
shasum -a 256 -c HelloX-1.0.4.pkg.sha256
```

看到 `OK` 表示文件与发布时的 SHA-256 校验值一致。
